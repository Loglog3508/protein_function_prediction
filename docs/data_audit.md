## 重复与泄漏

- 训练集和测试集之间没有重复 `protein_id`。
- 训练集和测试集之间没有完全相同的序列。
- 训练集内部存在重复序列。验证划分必须按序列分组，避免同一序列同时
  出现在训练集和验证集。

## 提交模板

`submit_template_v1.csv` 只有 8 条全零示例，ID 恰好等于测试集前 8 个
ID。它能够说明列名和数据类型，但不能作为正式提交的行骨架。正式提交
必须使用 `test.csv` 的全部 28,450 个 ID，并保持原始顺序，最终应有
28,450 行、501 列。

## 与原 README 的差异

原 README 中的 44,000/11,000 行、序列长度 100 至 500、平均 300、
标签密度约 3.4%、每条记录平均 17 个标签，以及“仅含 20 种标准氨基酸”
均与当前文件不符。上述 SHA-256 用于识别本报告对应的数据版本。
