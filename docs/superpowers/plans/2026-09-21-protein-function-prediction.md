# 蛋白质功能预测竞赛执行计划

> **进度同步规则（执行前必读）：** 每完成一个步骤，立即将对应的 `- [ ]` 改为 `- [x]`；阶段内所有步骤完成后，再勾选文首“阶段总览”中的对应阶段。若步骤受阻，不要勾选，在该步骤下一行补充 `> 阻塞：原因 / 负责人 / 下一步 / 更新时间`。任何成员开始工作前，先阅读本文件并更新“当前状态”，避免重复执行。
>
> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**目标：** 基于竞赛提供的蛋白质序列训练多标签分类模型，在保证提交格式与实验可复现的前提下提升 500 个功能标签的 Macro F1，并完成可运行代码、提交文件和分析报告。

**总体方案：** 先核对数据与规则并建立可靠的本地验证体系，再复现当前随机森林基线，随后以字符级 k-mer TF-IDF + 线性多标签分类器为主线优化特征、类别不平衡与逐标签阈值。最终通过交叉验证、模型融合和严格的提交校验选择方案，同时沉淀实验记录、报告图表与复现脚本。

**技术栈：** Python、pandas、NumPy、SciPy、scikit-learn、Jupyter Notebook；预训练蛋白质模型仅在官方规则明确允许外部预训练权重时使用。

**规格依据：** `README.md`、`RULES.md`、`baseline-v2.ipynb`、竞赛报告模板及 `data/` 中的实际文件。

## 全局约束

- 评估指标为 500 个标签的 Macro F1；本地实现必须与官方“跳过评估子集中无正样本标签”的口径一致。
- 提交结果只能包含 `protein_id` 与 `label_0` 至 `label_499`，标签值必须为整数 0 或 1。
- 未获得官方明确许可前，不引入外部训练数据；预训练模型权重是否允许必须先核验并记录依据。
- 每次实验必须记录代码版本、数据版本、随机种子、特征、模型参数、阈值策略、运行时间和验证分数。
- 不覆盖已有实验产物；提交文件和指标文件使用带日期或实验编号的名称保存。
- 所有最终结论必须来自可复现的本地验证或平台提交结果。

### 阶段 2：完成数据分析与验证集设计

### 阶段 4：实现 k-mer TF-IDF 线性基线

**核心接口：** `build_kmer_vectorizer(...)`、`fit_label_models(...)`、`evaluate_predictions(...)`

- [ ] **4.1 建立最小特征**：先实验字符级 3-mer，再实验 3 至 5-mer，参数全部写入配置。
- [ ] **4.2 控制内存**：记录词表与稀疏矩阵规模，通过 min_df、max_features 和数据类型限制资源，不转为稠密矩阵。
- [ ] **4.3 训练线性模型**：比较 LogisticRegression 与 SGDClassifier，并处理类别不平衡。
- [ ] **4.4 保存连续分数**：保存验证集和测试集概率或决策分数，调阈值时不重复训练。
- [ ] **4.5 公平比较**：使用相同验证索引比较 Macro F1、训练时间、推理时间和内存。
- [ ] **4.6 阶段验收**：得到完整 500 标签结果，并明确是否优于随机森林后勾选阶段 4。

### 阶段 5：优化不平衡处理与预测阈值

- [ ] **5.1 扫描统一阈值**：在验证集扫描 0.05 至 0.95 等候选值，记录最佳 Macro F1。
- [ ] **5.2 搜索逐标签阈值**：按标签选择最佳 F1 阈值，无正样本标签按官方指标跳过。
- [ ] **5.3 防止阈值过拟合**：比较固定验证、OOF 和阈值收缩；稀有标签优先使用全局或分组阈值。
- [ ] **5.4 比较类别权重**：对 balanced、无权重和自定义正例权重做单变量实验。
- [ ] **5.5 检查预测标签数**：比较真实与预测的每样本标签数量分布，识别过预测或欠预测。
- [ ] **5.6 固化阈值文件**：保存 500 个阈值、生成方式和对应验证分数。
- [ ] **5.7 阶段验收**：阈值策略在未参与选阈值的数据上仍有稳定收益后勾选阶段 5。

### 阶段 6：开展特征、模型与融合实验

- [ ] **6.1 扩展统计特征**：实验二肽频率、长度分桶、疏水/极性等仅由序列计算的特征。
