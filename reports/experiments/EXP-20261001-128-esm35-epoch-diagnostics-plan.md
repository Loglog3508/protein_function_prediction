## 范围与方法

1. 核验 EXP-127 的完整历史、逐轮 SHA256、固定验证 IDs/标签列；训练支持度只由固定训练 IDs 计算，验证支持度单独报告。
2. 复用五 seed（17、31、42、73、101）两折交叉拟合，精确逐标签阈值、全局 0.02 网格、shrinkage=25；必须复现既有逐轮校准 F1 和正例率。
3. 对全部 500 标签计算 ROC AUC、AP、默认/校准 F1、TP/FP/FN、预测正例数与分数分布。训练支持度按 0～19、20～99、100～999、1000+ 分层；验证支持度按 0、1～5、6～10、11～20、21～50、51+ 分层。
4. 以 epoch6 为基准配对比较 epoch7～10，计算每个标签对全局 Macro F1/AUC 变化的贡献、负向贡献集中度，以及新出现的无预测、无 TP 与分数压缩现象。零验证正例标签不能被误报为 F1 坍缩。
5. 使用相同 selection/evaluation 折，将 epoch6 selection-fold 阈值应用到后续轮 evaluation-fold 分数，分解“固定决策规则下的分数变化”和“重新拟合阈值变化”。该分解有顺序依赖，不是训练内部机制的因果证明。

## 本次新增的正负可分性诊断

- 逐标签指标为 `(正例分数中位数 - 负例分数中位数) / 负例分数标准差(ddof=0)`；这是标准化中位数间隔，不是真正的分布重叠系数。缺少类别或负类标准差为 0 时记缺失，不用任意 epsilon 掩盖退化。
- 全部标签训练支持度为 1278～73654，原固定支持度层全部落在 `1000+`，因此另外按固定训练支持度稳定排序三等分为低/中/高层，数量为 167/167/166；同支持度以原标签顺序打破并列，不用验证分数选分组。
- 每轮输出 500 个间隔值，另保存分位数/描述性分箱、高中低层 AUC、校准过预测标签数与超额正例集中度，以及高减低的 label-bootstrap 描述性区间。
- 现有精确阈值、0.02 全局网格、shrinkage=25、五 seed 保持原协议，不搜索新参数。分析只证实验证分数上的可分性，不能直接证实训练集或隐表示的因果机制。
