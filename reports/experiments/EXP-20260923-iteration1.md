# 第一次提分迭代：低正则与扩展 k-mer 词表

- 日期：2026-09-23
- 固定划分：90,920 条训练、22,876 条验证，seed 42
- 主评价：500 标签双向交叉拟合收缩阈值 Macro F1
- 规则约束：仅使用竞赛 CSV，不使用外部数据或预训练权重

## 筛选设计

旧实验使用前 50 个高频标签筛选超参数，会系统性低估中尾部标签的难度。本轮先按训练集标签支持度排序，再等距抽取 100 个标签，覆盖完整频率区间。所有候选共享固定数据划分、标签子集和 TF-IDF 矩阵。

## 正则与参数平均

30,000 维 3-5-mer TF-IDF 上的筛选结果：

| SGD 配置 | 100 标签交叉拟合 Macro F1 |
| --- | ---: |
| `alpha=5e-5` | 0.311967 |
| `alpha=3e-5` | 0.326438 |
| `alpha=2e-5` | 0.334873 |
| `alpha=1e-5` | 0.343068 |
| `alpha=7e-6` | **0.345899** |
| `alpha=5e-6` | 0.345657 |
| `alpha=3e-6` | 0.345601 |
| `alpha=1e-6` | 0.339386 |

峰值位于 `alpha=7e-6` 附近；`1e-6` 已出现明显回落。`average=True` 在 `5e-5`、`3e-5`、`2e-5` 和 `1e-5` 四个配对实验中均低于普通 SGD，因此淘汰。

## 词表容量

| 最大词表 | alpha | 100 标签交叉拟合 Macro F1 |
| ---: | ---: | ---: |
| 30,000 | 7e-6 | 0.345899 |
| 60,000 | 7e-6 | 0.363619 |
| 120,000 | 7e-6 | 0.371390 |
| 120,000 | 5e-6 | **0.372594** |

扩大词表持续提升，说明原 30,000 维特征截断丢失了有判别力的较长 motif。120,000 维训练矩阵约 713 MB，资源消耗仍可控。

## 完整 500 标签结果

最终验证候选为 120,000 维 3-5-mer TF-IDF、balanced SGD、`alpha=5e-6`：

| 指标 | 旧主模型 | 第一次迭代 | 绝对提升 |
| --- | ---: | ---: | ---: |
| 固定阈值 0.5 Macro F1 | 0.242469 | 0.362882 | +0.120413 |
| 双向交叉拟合收缩阈值 Macro F1 | 0.317516 | **0.379956** | **+0.062440** |
| 交叉拟合预测正例率 | 7.375% | 5.894% | -1.481 pp |

交叉拟合得分相对提升约 19.7%。固定阈值本身已经超过旧模型的阈值优化结果，说明主要收益来自模型排序和分类能力，而不是阈值搜索。

## 阈值稳定性

使用 0.01 阈值网格，在 seed 11、23、42、67、101 的五次双向二分上复核：

| 收缩强度 | 平均 Macro F1 | 标准差 | 最小值 | 最大值 |
| ---: | ---: | ---: | ---: | ---: |
| 10 | 0.380013 | 0.000552 | 0.379295 | 0.380743 |
| 25 | **0.380168** | 0.000541 | 0.379376 | 0.380817 |
| 50 | 0.380023 | 0.000428 | 0.379459 | 0.380570 |

结果对阈值二分 seed 稳定，保留收缩强度 25。正式阈值仍使用原有 0.05 网格，避免为了约 0.0002 的均值差异增加阈值选择复杂度。
