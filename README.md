# 电力现货市场价格预测与新能源消纳分析

**2026年辽宁省大数据应用与分析大赛 · 赛道1（数智分析赛）**

> 以欧洲电力现货市场（德国-卢森堡 DE_LU）为研究对象，围绕“日前现货电价预测”与“新能源消纳分析”两条主线，形成从数据到建模再到可视化的完整数智分析作品。

## 项目背景

在“双碳”目标与新型电力系统建设背景下，风电、光伏等新能源大规模并网，电力现货市场的价格波动显著加剧，甚至出现负电价。准确预测电价并量化新能源消纳规律，是发电企业报价、购电决策、储能套利与新能源调度的重要支撑。

## 研究目标

1. 预测未来 24 小时的日前现货电价；
2. 量化新能源（风、光）渗透率对电价水平与波动的影响，识别负电价的出现规律；
3. 形成报价、储能充放电与新能源消纳的可落地建议。

## 数据

- **来源**：Open Power System Data（OPSD）/ ENTSO-E，免费开放。
- **区域**：德国-卢森堡（DE_LU）。
- **字段**：日前电价、实际/预测负荷、光伏/风电出力（含陆上、海上）。
- **文件**：`de_lu_energy.csv`（原始抽取）与 `de_lu_energy_clean.csv`（清洗后）。
- **清洗**：见 `de_lu_cleaning_log.md`；运行 `python clean_de_lu_energy.py` 可复现。

## 方法

- 探索性分析（EDA）与 STL 时序分解；
- 特征工程：滞后项、滚动统计、风光渗透率、日历特征；
- 模型：持续法/ARIMA（基线）、XGBoost/LightGBM、LSTM、TFT（概率预测）；
- 评估指标：MAE、RMSE、MAPE、涨跌方向准确率；
- 可解释性：SHAP 特征归因。
